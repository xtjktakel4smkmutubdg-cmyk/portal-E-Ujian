# Portal Ujian Online (Moodle Clone)

A Moodle-like Learning Management System built with React, Express, and Supabase.

## Roles
There are exactly two roles in this system:
- **Admin**: Has full access. Can CRUD exams, questions, users, view all results, grade essays.
- **Siswa**: Can only login, view exams, take exams, and view their own results. (Registration is disabled).

## Default Admin Credentials
- **Username**: admin
- **Password**: adminpassword123

## Setup

1. Make sure you have Node.js installed.
2. Install dependencies:
   `npm install`
3. Run both frontend and backend locally:
   `npm run dev &`
